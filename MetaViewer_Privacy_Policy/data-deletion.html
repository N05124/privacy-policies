Data Deletion Instructions · Updated November 18, 2026

This is MetaViewer's public data deletion instructions page for its personal-project Instagram and Facebook integrations. You can use these steps without providing a password, access token or other secret to the developer.

Disconnect an account

  1. Open MetaViewer on the device where the account was connected.
  2. Open Profiles or the profile list on the Demo screen.
  3. Select the connected profile card.
  4. Select Log out / disconnect. The app removes its locally stored authorization for that account unless the same session is intentionally shared by another profile card.

Disconnecting is not the same as deleting a profile card. It can leave a local display name or username visible in MetaViewer.

Remove locally saved profile data

  1. Open the profile card again.
  2. Select Remove profile card and confirm the deletion.
  3. Repeat for any other cards that refer to the same connected account.

Removing a card deletes its local profile entry and associated connection metadata. The app also attempts to remove any unshared Keychain session used by that card. If the device is lost or you cannot access the app, revoke the authorization from Meta using the instructions below.

Delete local drafts and app data

MetaViewer saves user-created drafts in local application storage. Removing an account card does not by itself guarantee that unrelated drafts are deleted. To clear all of the app's locally stored drafts, profile preferences and on-device files, remove the MetaViewer application from the device after disconnecting the accounts. In-memory demo logs and pending test queues are cleared when the app process ends.

Keychain items may survive app removal or a later reinstall. For that reason, disconnect each connected account first when possible and also revoke authorization within Meta.

Revoke access within Meta

In Facebook or Instagram, open the account's current settings for connected apps and websites or business integrations, locate MetaViewer or the corresponding developer integration and remove its access. Meta's settings labels can change. Revocation limits future API access even if you no longer have the device that originally connected the account.

For an Instagram professional account connected through Facebook Pages, review the relevant Facebook Business integrations and Page permissions as well.

What the authentication server retains

The MetaViewer OAuth service is designed to use a short-lived one-time authorization transaction. It stores a hash of the temporary state and proof with an expiration of approximately ten minutes, rather than maintaining a persistent server-side database of your Instagram account content or access tokens. Service security logs may contain technical metadata such as timestamps, IP addresses and response codes; their retention depends on the actual hosting configuration.

The current personal-project implementation does not provide a remote account-data deletion API or an automated Meta signed-request deletion callback. This page provides self-service deletion steps. If the app begins retaining Meta account data on a hosted service, its deletion process and this page must be updated before broader access is enabled.

What is not deleted

Deleting MetaViewer data does not delete your Instagram or Facebook accounts, posts, comments or messages already stored by Meta. Manage that content through Meta's own products. It also cannot remotely erase data from a lost device or automatically delete data retained independently by an operating-system or hosting provider.

Questions and requests

Contact details for privacy and deletion questions will be published here. Until a private contact mechanism is available, use the self-service steps above. Never disclose your password, access token, authorization code or personal account records in public GitHub issues.

For details on what MetaViewer processes, read its Privacy Policy.
